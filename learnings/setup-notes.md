# Setup Learnings Log

This journal keeps a simple running story of what we did, why we did it, and the exact commands that were used. Read the summary first to grasp the flow, then dive into the detailed table if you want specifics.

## Quick Overview (Plain English)

1. Looked inside the project folder to make sure we would not overwrite anything important.
2. Tried to generate a brand-new Next.js app with TypeScript, Tailwind, and pnpm; the first attempts failed because the folder was not empty and pnpm was missing.
3. Installed pnpm globally so the generator could use it, then scaffolded the app in a temporary folder (which finally worked).
4. Removed the temporary git history and moved all generated files into our main workspace.
5. Renamed the package to `portfolio` and recorded the pnpm version so future installs stay consistent.
6. Saved the default README so we know what needs to be rewritten later.
7. Initialised git, renamed the default branch to `main`, and created the active phase branch `phase/01-foundation` so work aligns with the roadmap.
8. Replaced the default README with a project-specific overview so new contributors understand the plan immediately.
9. Added issue/PR templates, CODEOWNERS, and `docs/setup.md` to align collaboration with the roadmap.
10. Reinstalled dependencies so pnpm could rebuild its virtual store after moving scaffolding files.
11. Installed the tooling stack (Prettier, ESLint plugins, Husky, lint-staged, Commitlint, Vitest, Testing Library) and wired scripts, configs, and hooks.
12. Tightened TypeScript settings, added Prettier/editor config, created a typed-routes helper, and introduced a basic Vitest sanity test.
13. Added `.env.example`, CI workflow, and documentation updates (`README`, `docs/setup.md`, `docs/mcp-setup.md`) so contributors know how to configure secrets and MCP tokens.
14. Ran lint, typecheck, tests, format, and build commands to verify the new tooling setup end-to-end.
15. Installed UI libraries, built the global theme/layout system, and scaffolded placeholder pages for About, Projects, Blog, and Contact.
16. Defined Tailwind design tokens, added shared Badge component, and refreshed the homepage hero to showcase the new primitives.
17. Created Supabase schema, data sync services, and scheduled automation for Phase 02 activity tracking.
